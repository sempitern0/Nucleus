# Terrain examples

These scenes are small executable fixtures for the optional terrain module.
They use only native Godot resources and procedural noise, so no external
heightmap or texture asset is required.

| Scene | Purpose |
| --- | --- |
| `terrain_preview.tscn` | Cheap low-resolution preview path, no collision |
| `terrain_single.tscn` | One complete generated heightfield |
| `terrain_grid.tscn` | Chunked complete area with continuous sampling |
| `terrain_linear.tscn` | Fixed linear strip for corridor/traversal worlds |
| `terrain_islands.tscn` | Deterministic archipelago with underwater collision holes |
| `terrain_streaming.tscn` | Runtime chunk window following a moving target |

Open `terrain_preview.tscn` in the editor to see the preview generated by its
example driver. The other scenes generate when run with **F6**.

Every generator example assigns `NucleusTerrainMaterialProfile`, which also
exercises the built-in layered terrain shader even when no texture layers are
configured.

The scenes are examples, not mandatory dependencies. Copy the setup you need
into a game-owned scene and tune profiles against the actual performance target.
